# Madar Landing Page 🚀

> واجهة ويب حديثة للصفحة الرئيسة لمشروع Madar، مبنية بـ Next.js و Tailwind CSS، مع دعم استضافة Vercel. 

[![Next.js](https://img.shields.io/badge/Next.js-15.2.9-black?style=for-the-badge&logo=next.js)](https://nextjs.org/)
[![React](https://img.shields.io/badge/React-19.0.0-61DAFB?style=for-the-badge&logo=react&logoColor=black)](https://react.dev/)
[![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-4-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)](https://tailwindcss.com/)
[![Vercel](https://img.shields.io/badge/Deployed_on-Vercel-000000?style=for-the-badge&logo=vercel)](https://vercel.com/)

A sleek, responsive landing page for the Madar project built with **Next.js (App Router)**, **React**, and **Tailwind CSS**. The page showcases a modern UI with smooth animations, dynamic sections, and dark‑mode support.

## ✨ المميزات | Features

| الميزة | Description |
| :--- | :--- |
| 📱 **تصميم متجاوب** | Fully responsive layout that works on mobile, tablet, and desktop. |
| 🎨 **ثيمات** | Light & dark mode support via `next-themes`. |
| ✨ **حركة سلسة** | Subtle animations using `framer‑motion` for an engaging experience. |
| 🗂️ **مكونات قابلة لإعادة الاستخدام** | Reusable UI components (buttons, cards, hero sections). |
| 🚀 **أداء عالي** | Optimized images, fonts, and lazy loading for fast load times. |

## 🛠️ التقنيات المستخدمة | Tech Stack

### Frontend
- **[Next.js 15.2.9](https://nextjs.org/)** – React framework with App Router.
- **[React 19.0.0](https://react.dev/)** – Component‑based UI library.
- **[Tailwind CSS 4](https://tailwindcss.com/)** – Utility‑first CSS framework.
- **[Framer Motion 11.11.17](https://www.framer.com/motion/)** – Animations & transitions.
- **[Next Themes 0.4.3](https://github.com/pacocoursey/next-themes)** – Dark/Light mode handling.

### Deployment
- **Vercel** – Serverless hosting with automatic CI/CD.

## 📁 هيكل المشروع | Project Structure

```text
src/
├── app/               # Next.js App Router pages & layouts
│   ├── layout.tsx     # Global layout with theme provider
│   ├── page.tsx       # Home / landing page content
│   └── components/    # UI components (Hero, Features, Footer, ...)
├── public/            # Static assets (images, icons)
└── styles/            # Global Tailwind CSS configuration
```

## 📦 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/zain-zaqout/madar.git
cd madar-landing-page
```

### 2. Install Dependencies

```bash
npm install
```

### 3. Run the Development Server

```bash
npm run dev
```

Visit `http://localhost:3000` to view the landing page locally.
